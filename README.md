# Brew Haven Café Demo

A responsive, interactive café website prototype built as a lightweight Vite-style frontend without Lovable.

## Included
- Responsive desktop/mobile layout
- Sticky navigation and mobile menu
- Menu category filtering
- Add-to-order cart drawer with quantity controls
- Demo checkout interaction
- Reservation form with success state
- Newsletter signup state
- Café story, specials, journal and contact sections
- Local image assets sourced from online café/coffee photography
- Google Fonts: Playfair Display + DM Sans

## Run
The project is intentionally simple and can be served by any static web server.

Example:
```bash
python3 -m http.server 4173
```

Then open:
`http://localhost:4173`

No backend is required for this demo. Reservation, checkout and newsletter actions are front-end demo states ready to be connected to a real backend/payment/POS system later.
